# Movie Recommender System

## 1. 프로젝트 개요

이 프로젝트는 C++로 구현한 영화 추천 시스템입니다.  
영화, 사용자, 평점 데이터를 CSV 파일로 관리하고, 사용자의 평점 데이터를 기반으로 영화 추천 기능을 제공합니다.

M3에서는 사용자 간 유사도 계산, 사용자 기반 협업 필터링 추천, 장르 기반 추천, 파일 입출력 기능을 구현했습니다.  
M4에서는 코드 리뷰 체크리스트를 반영하여 main 흐름을 분리하고, 검색 강화, 장르 필터, 통계 기능, 사용자 취향 프로필, 추천 이유 설명 기능을 추가했습니다.

## 5. 데이터 파일 구조

프로그램은 `data/` 폴더 안의 CSV 파일을 사용합니다.

```txt
data/
├── movies.csv
├── users.csv
└── ratings.csv
```

### movies.csv

영화 정보를 저장합니다.

```csv
id,title,genre,releaseYear
101,인터스텔라,SF,2014
```

### users.csv

사용자 정보를 저장합니다.

```csv
id,name,email
1,유지민,yujimin@naver.com
```

### ratings.csv

사용자가 영화에 남긴 평점을 저장합니다.

```csv
userId,movieId,score
1,101,5.0
```

## 6. 주요 기능

### 0번. 종료

프로그램을 종료하고 현재 데이터를 CSV 파일에 저장합니다.

### 1번. 영화 추가

새 영화를 추가합니다.  
이미 존재하는 영화 ID는 추가할 수 없습니다.  
추가 후 영화 ID 기준으로 정렬됩니다.

### 2번. 제목으로 영화 검색

영화 제목을 검색합니다.  
M4에서 검색 기능을 강화하여 공백을 무시하고 부분 검색이 가능하도록 했습니다.

예시:

```txt
귀멸의칼날
귀멸의 칼날
칼날
```

위 입력들은 모두 `귀멸의칼날` 영화를 검색할 수 있습니다.

### 3번. 전체 영화 목록 출력

등록된 모든 영화를 영화 ID 순으로 출력합니다.

### 4번. 평점순 영화 목록 출력

영화 평균 평점이 높은 순서로 영화를 출력합니다.

### 5번. 사용자 추가

새 사용자를 추가합니다.  
이미 존재하는 사용자 ID는 추가할 수 없습니다.

### 6번. 전체 사용자 목록 출력

등록된 모든 사용자를 출력합니다.

### 7번. 평점 입력

사용자가 특정 영화에 평점을 입력합니다.

검사하는 조건은 다음과 같습니다.

- 존재하는 사용자 ID인지 확인
- 존재하는 영화 ID인지 확인
- 평점이 0.0 이상 5.0 이하인지 확인
- 같은 사용자가 같은 영화에 중복 평점을 입력했는지 확인

### 8번. 특정 영화의 평점 목록 출력

특정 영화 ID에 대해 등록된 모든 평점을 출력합니다.

### 9번. 전체 평점 목록 출력

전체 평점 데이터를 출력합니다.  
평점은 userId, movieId 기준으로 정렬됩니다.

### 10번. 사용자 유사도 비교

기준 사용자와 다른 사용자들의 유사도를 계산하여 출력합니다.  
가장 유사한 사용자가 여러 명이면 모두 출력합니다.

### 11번. 영화 추천

두 가지 방식의 추천 결과를 출력합니다.

1. 사용자 기반 협업 필터링 추천
2. 장르 기반 추천

또한 M4에서 추천 이유 설명 기능을 추가하여, 왜 해당 영화가 추천되었는지도 함께 출력합니다.

### 12번. 통계 보기

통계 메뉴를 제공합니다.

```txt
1. 전체 평균 평점
2. 장르별 평균 평점
3. 평점 Top 10 영화
0. 돌아가기
```

### 13번. 장르별 영화 보기

현재 등록된 장르 목록을 먼저 출력한 뒤, 사용자가 입력한 장르에 해당하는 영화만 출력합니다.

예시:

```txt
검색할 장르: SF
```

### 14번. 사용자 취향 프로필

특정 사용자의 평점 데이터를 분석하여 취향 프로필을 출력합니다.

출력 정보:

- 평가한 영화 수
- 사용자 평균 평점
- 선호 장르 TOP 3
- 높게 평가한 영화 TOP 5

## 7. 클래스 구조

### Movie

주요 데이터:

- 영화 ID
- 제목
- 장르
- 개봉 연도
- 평점 총합
- 평점 개수

주요 기능:

- 평균 평점 계산
- 평점 추가
- 영화 정보 출력

---

### User

사용자 한 명의 정보를 표현하는 클래스입니다.

주요 데이터:

- 사용자 ID
- 이름
- 이메일

---

### Rating

평점 한 개를 표현하는 클래스입니다.

주요 데이터:

- 사용자 ID
- 영화 ID
- 평점

잘못된 평점은 유효하지 않은 평점으로 처리합니다.

---

### BaseManager

Manager 클래스들의 공통 부모 클래스입니다.

순수 가상 함수:

```cpp
loadFromFile()
saveToFile()
size()
```

`MovieManager`, `UserManager`, `RatingManager`가 `BaseManager`를 상속받고, 세 함수를 `override`로 구현합니다.

---

### MovieManager

영화 데이터를 관리하는 클래스입니다.

주요 기능:

- 영화 추가
- 영화 검색
- 전체 영화 출력
- 평점순 영화 출력
- 영화 ID 검색
- 장르 필터
- 장르 기반 추천
- 전체 평균 평점 계산
- 장르별 평균 평점 계산
- Top N 영화 반환
- 사용자 취향 프로필 출력
- movies.csv 파일 입출력

---

### UserManager

사용자 데이터를 관리하는 클래스입니다.

주요 기능:

- 사용자 추가
- 전체 사용자 출력
- 사용자 존재 여부 확인
- users.csv 파일 입출력

---

### RatingManager

평점 데이터를 관리하는 클래스입니다.

주요 기능:

- 평점 추가
- 중복 평점 방지
- 특정 영화의 평점 출력
- 전체 평점 출력
- 특정 사용자의 평점 목록 반환
- 평점을 남긴 전체 사용자 ID 반환
- ratings.csv 파일 입출력

---

### SimilarityCalculator

두 사용자의 평점 목록을 비교하여 유사도를 계산하는 클래스입니다.

유사도 공식:

```txt
similarity = commonCount * 10.0 - scoreDiffSum
```

- commonCount: 두 사용자가 공통으로 평가한 영화 수
- scoreDiffSum: 공통 영화에 대한 평점 차이의 합

공통 영화가 없으면 `-100.0`을 반환합니다.

---

### Recommender

사용자 기반 협업 필터링 추천을 담당하는 클래스입니다.

주요 기능:

- 기준 사용자와 다른 사용자들의 유사도 계산
- 유사 사용자 상위 K명 선택
- 유사 사용자가 높게 평가한 영화 중 기준 사용자가 아직 보지 않은 영화 추천
- 추천 이유 출력

추천 점수는 다음 방식으로 계산합니다.

```txt
추천 점수 = (유사도 × 평점)의 합 / 유사도의 합
```

---

### MovieRecommenderApp

M4에서 추가한 앱 실행 흐름 관리 클래스입니다.

기존에는 `main.cpp`가 메뉴 출력, 입력 처리, 데이터 로드/저장, 추천 실행을 모두 담당했습니다.  
M4에서는 이 흐름을 `MovieRecommenderApp` 클래스로 분리했습니다.

현재 `main.cpp`는 다음처럼 프로그램 시작점 역할만 담당합니다.

```cpp
int main() {
    MovieRecommenderApp app;
    app.run();
    return 0;
}
```

## 8. 추천 알고리즘

### 사용자 기반 협업 필터링 추천

1. 기준 사용자의 평점 목록을 가져옵니다.
2. 다른 사용자들과 유사도를 계산합니다.
3. 유사도 상위 K명을 선택합니다.
4. 유사 사용자들이 4.0점 이상 준 영화 중 기준 사용자가 아직 보지 않은 영화를 후보로 모읍니다.
5. 영화별 추천 점수를 계산합니다.
6. 추천 점수가 높은 순으로 정렬합니다.
7. 상위 N개 영화를 추천합니다.

---

### 장르 기반 추천

1. 사용자의 평점 목록을 가져옵니다.
2. 사용자가 이미 평가한 영화는 제외합니다.
3. 사용자가 높게 평가한 영화의 장르를 선호 장르로 판단합니다.
4. 아직 보지 않은 영화 중 선호 장르와 맞는 영화를 후보로 선택합니다.
5. 장르 선호도와 영화 평균 평점을 기반으로 추천 점수를 계산합니다.
6. 상위 N개 영화를 추천합니다.

## 9. M4 확장 기능

M4에서 추가한 기능은 다음과 같습니다.

### 1. main 분리

`main.cpp`의 책임을 줄이고, 전체 메뉴 흐름을 `MovieRecommenderApp` 클래스로 분리했습니다.

### 2. 검색 강화

공백을 제거한 뒤 부분 문자열 검색을 수행합니다.

예시:

```txt
귀멸의칼날
귀멸의 칼날
칼날
```

위 입력이 모두 검색됩니다.

### 3. 장르 필터

사용자가 장르를 입력하면 해당 장르의 영화만 출력합니다.  
장르 목록도 먼저 보여줍니다.

### 4. 통계 기능

전체 평균 평점, 장르별 평균 평점, 평점 Top 10 영화를 출력합니다.

### 5. 사용자 취향 프로필

특정 사용자의 평점 데이터를 분석하여 평균 평점, 선호 장르, 높게 평가한 영화를 출력합니다.

### 6. 추천 이유 설명

추천 영화가 왜 추천되었는지 함께 출력합니다.

사용자 기반 추천에서는 유사 사용자의 높은 평점을 근거로 설명합니다.  
장르 기반 추천에서는 사용자의 장르 선호도를 근거로 설명합니다.
